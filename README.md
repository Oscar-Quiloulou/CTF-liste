## 🚀 Comment lancer un challenge

Chaque dossier contient les fichiers nécessaires (code source, binaire, ou fichier de déploiement).

1. Rends-toi dans le dossier du challenge : `cd CTF_1`
2. Suis les instructions du fichier d'installation (ou lance le Docker s'il y en a un : `docker-compose up --build`)
3. Bonne chance pour trouver le flag !
