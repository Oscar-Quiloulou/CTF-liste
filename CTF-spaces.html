Niveau 1 — Le Coffre de l'Admin

Un simple coffre protégé par un mot de passe. Ce dernier est encodé en base64 quelque part dans le code source. Ouvre les DevTools (F12) et fouille.

🔒

Niveau 2 — Le Message Crypté

Le mot de passe a subi deux transformations : il a d'abord été inversé, puis chiffré avec ROT13. À toi de le remettre dans le bon sens.

🔒

Niveau 3 — Le Sceau Binaire

Le mot de passe a été chiffré avec un XOR octet par octet. La clé et le tableau de codes sont dans le JavaScript. Inverse l'opération.

🔒

Niveau 4 — Le Boss Final

Le mot de passe est découpé en 3 morceaux cachés à 3 endroits :
• Partie 1 → un data-attribute HTML (base64)
• Partie 2 → une variable CSS (hexadécimal)
• Partie 3 → le JavaScript (inversé)
Assemble-les : partie1 + partie2 + partie3.
